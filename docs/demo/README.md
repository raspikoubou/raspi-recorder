# ブラウザー体験デモ

[デモを開く](https://raspikoubou.github.io/raspi-recorder/demo/)

製品のライブ・録画・設定画面を、生成したサンプル映像で操作できます。設定とパスワードの変更は開いているページ内で有効になり、ページを開き直すと初期状態に戻ります。デモ専用のパスワードを使用してください。実際のカメラ・保存媒体・OSの変更は行いません。

GUIは製品のHTMLテンプレート、JavaScript、CSSから作成します。見た目と操作を製品の画面にそろえ、カメラや保存先の応答をデモ用データで提供します。録画再生とダウンロードには、15秒の無音のサンプルMP4を使います。録画時刻とストレージ容量は操作用の表示例です。

`source.json`に対象の製品ソースとファイルのSHA-256を記載しています。

## 再生成

`python scripts/build_browser_demo.py`で製品UIをコピーします。サンプル映像を作り直す場合は、Pillowとimageio-ffmpegをインストールした環境で`python scripts/build_browser_demo.py --media`を実行します。公開検査は指定したサンプルMP4のSHA-256を照合します。映像を変更した場合は、その内容と公開検査の照合値を確認してください。

サンプル映像とデモのソースは本リポジトリのMITライセンスに従います。
