# らずぱいドライブレコーダー 利用者向け説明書

初めて使う方は、1→2→3の順に読みます。導入済みの機器を操作する方は、取扱説明書の「目的から探す」から必要な操作へ進んでください。

| 説明書 | 分かること |
|---|---|
| **1. [概要説明書](概要説明書.md)** | 用途、システム構成、必要な物、録画の仕組み、容量管理、使用条件・免責 |
| **2. [インストール説明書](インストール説明書.md)** | Windows／MacでのSD作成、Piへの接続、公開Releaseの取得・照合・導入、初回設定、録画確認、自動起動 |
| **3. [取扱説明書](取扱説明書.md)** | 日付・時間で録画を選ぶ、再生・保存、カメラ・音声・ストレージ・パスワード・日時・更新の操作 |

図はGitHubのMarkdown表示で確認できます。スクリーンショットは相対パスで参照するため、配布物から読む場合も`images`フォルダーを一緒に残してください。画像の出所と撮影方法は[画像について](images/manual/README.md)に記載しています。

**最初に確認する注意：** 新規導入時のログイン保護・管理者保護はOFFです。HTTP通信は暗号化されません。信頼できるLANまたは保護されたVPN内で使用し、インターネットへ直接公開しないでください。録画・音声の欠落や消失、更新・復旧失敗が起こり得るため、重要な映像は別の媒体へ保存します。詳しい注意と免責は各説明書を確認してください。
