# インストール説明書

図解・スクリーンショット付きの説明書を、配布アーカイブにも含まれる`user`フォルダーにまとめました。

1. [概要説明書](user/概要説明書.md) — できること、必要機器、録画の仕組み、制約・免責・リスク
2. [インストール説明書](user/インストール説明書.md) — OS用SD作成、SSH、公開Release取得、導入、初回設定、動作確認
3. [取扱説明書](user/取扱説明書.md) — ライブ、録画検索・再生・保存・削除、設定、セキュリティ、更新、点検・トラブル対応

初めて導入する場合は、概要を確認してからインストール説明書へ進んでください。導入済みの機器を更新する際は、SDを作り直さず、取扱説明書の更新手順を使用します。
