# らずぱいドライブレコーダー

Raspberry PiとUSBカメラで映像を記録し、LAN内のWebブラウザからライブ表示・検索・再生・持ち出しを行う一般用途のソフトウェアです。

[ブラウザーで体験する](https://raspikoubou.github.io/raspi-recorder/demo/) · サンプル映像でライブ・録画・設定画面を操作できます。

## 主な機能

- 任意の省電力モード（対応設定内で解像度・fpsを下げ、音声を停止。通常設定は保持）
- 録画fps・画質と独立した、トップ画面の1fps自動画像プレビュー
- 5・10・15・20・30・60分の保存単位と、日付・録画区間リストからの選択
- MP4/H.264録画、録画一覧・再生・再生位置の移動
- 確定済みMP4のダウンロード、異常録画の個別ダウンロード
- microSDまたは対応するUSB媒体への保存、容量管理、ログイン用／管理者用パスワード

配布物は、製品ソースと図解・スクリーンショット付きの利用者向け説明書を含む`.tar.zst`と`SHA256SUMS`です。Python依存wheelはアーカイブへ含めず、Pi上でソースから構築します。PyAVはDebian TrixieのFFmpegと組み合わせるため`15.0.0`に固定しています。公開安定版は[GitHub Releases](https://github.com/raspikoubou/raspi-recorder/releases/latest)から取得します。

省電力モードは初期値OFFです。ONにするとカメラが提示する対応設定から現在値を超えない解像度・fpsを選び、音声を停止します。通常設定は保存したままなので、OFFに戻せば通常設定へ戻ります。低負荷化の程度は機器や構成によって異なります。

新規導入時はログイン保護・管理者保護ともOFFで、パスワード登録なしにトップ画面と設定を利用できます。設定画面から必要な保護だけを個別に有効化します。ログイン保護は閲覧・録画操作・MP4／ZIP取得を、管理者保護は設定保存・録画削除・時刻変更・更新適用・認証変更を守ります。どちらもOFFなら、それらの操作にパスワードを求めません。更新時も登録済みのパスワード・認証設定・録画を引き継ぎます。HTTPのため信頼できるLANまたはVPN内で利用してください。画面上部のメニューから、ライブ・録画・設定の各画面へ移動できます。

## 基準環境

- Raspberry Pi 5、RAM 4GB以上
- Raspberry Pi OS Lite 64-bit（Debian 13）
- Python 3.13

これは初版の基準環境であり、すべてのカメラ・電源・保存媒体の性能を保証しません。

初めて使う方に向けた3冊の説明書を用意しています。

初回導入にはインターネット接続が必要です。インストーラーはsystemd serviceを自動起動しません。カメラと保存先を確認し、必要な認証保護を設定してから次回起動時の自動開始を有効にしてください。各説明書では、操作する機器・入力例・成功時の表示と、録画中断やデータ消失などの注意を説明しています。

## 録画データとネットワーク

本ソフトウェアは安全装置・制御装置ではなく、録画の連続性、欠損のない保存、事故時の確実な記録を保証しません。重要な映像は別媒体へバックアップしてください。

Web UIはHTTPです。信頼できるLANまたはVPN内だけで使い、インターネットへ直接公開しないでください。録画映像や利用状況を開発元へ送信しません。

USB録画先はext4またはexFATに限ります。FAT32/NTFSは対応せず、アプリからフォーマットしません。USB上の既存データは録画管理の対象外です。
