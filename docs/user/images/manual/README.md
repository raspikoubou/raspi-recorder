# 説明書の図・画面画像について

## 画面例と図解

Web画面は、説明用のデータを表示したraspi-recorder 0.1.44の画面例です。青い縞の映像、機器名、容量、日時、録画一覧は説明用の値です。画面はブラウザやOSにより異なります。

端末画像はコマンドの表示例です。バージョン番号などの出力は例示のため、使用中の版で確認してください。入力には説明書本文のコピー用コマンドを使用してください。

構成図や操作の流れを示す図は説明用です。基板上の端子やコネクターの位置を示す実装図ではありません。

## Raspberry Pi Imagerの参考画像

次の3点は、同じ公開元の[24V Event Logger](https://github.com/raspikoubou/24v-event-logger-oss)の説明書から再利用した実画面です。

- `imager-device.png`：Raspberry Pi 5の選択。
- `imager-os-menu.png`：OS一覧。
- `imager-os-lite.png`：Raspberry Pi OS Lite 64-bitの選択。

元の参照コミットは `fdaf861d75556fafbde579f84557cbef18786c57` です。Imagerの版によって名称や順番が変わるため、本文のDebian 13（Trixie）・Lite・64-bitという条件も確認してください。Raspberry Pi等の名称・画面表示は各権利者に帰属します。
